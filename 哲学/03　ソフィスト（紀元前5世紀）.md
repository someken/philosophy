# アテネの民主政→自然（ビュシス）から人為（ノモス）へ
- ==アテネ==
	- 紀元前5世紀半ば、東方のアケメネス朝とのペルシア戦争（前500から前499年）に勝利し、デロス同盟の盟主となった都市国家。
	- 地中海東部の強国
- 民主制から貴族制
	- 陸軍の主力が貴族の騎兵から平民の重装歩兵部隊に代わる
	- 富裕層の平民が自費で武具を購入し、戦に参戦するようになった
	- 海軍の軍艦の漕ぎ手としてっも、平民が発言力を持つようなった
	- 陸・海の両方に力をもつようになり、参政権を主張して貴族と対立するようになる
- 自然（ビュシス）から人為（ノモス）へ
	- 貴族政から民主政へ移行したアテネでは、家柄や財産にかかわりなく、弁論・説得の能力があれば、市民のだれもが有力者になることができた
	- 人々の学問や思想の対象が、==自然（ビュシス）==から法・制度・習慣・道徳など人間が作った==人為（ノモス）==へと移っていった

# ソフィスト（職業教師）の相対真理
- ==ソフィスト==
	- 紀元前5世紀ごろ、ギリシアに登場
	- 謝礼（対価）を取る職業教師として、各ポリスを巡回しながら、青年たちに一般教養や法律・政治を教えた
- ==弁論術（レトリケー）==
	- 自らの見解に説得力を与え、雄弁に表現する技術
	- 競争に勝ち、自絶を認めさせることを目的としていたので、物事の心理を重視せず、とにかく相手を言いくるめようとする人が多いという、問題点があった
- ==プロタゴラス== ^2181a8
	- [[02 古代ギリシア自然哲学#^75ed21 | 根源（アルケー）]]を自然物に求めず、真偽の判断基準はここの考え方・感じ方だとし、==「万物の尺度は人間である」==と==人間中心主義」==を打ち出した
	- 神の存在に懐疑的で、==心理の物差しは人それぞれ異なる==という、主観的な==相対真理==を唱えた
- ==ゴルギアス==
	- 演説の名手で、当時、ゴルギアス流に話すのが流行した
	- 「何も存在しない。存在しても認識され得ない。認識しても伝達され得ない」という言葉を残す
	- 仮に何かが存在したとしても、尺度がことなる他人と共有することはできないので、それは存在しないのと同じである
	- 個々の間隔から得た知識すら懐疑的に考え、プロタゴラスと同じように==絶対的心理を否定==した

# 詭弁の横行とアテネ
- ソフィストたちは、「世界のありかたや人の生き方に、自然のような必然性や絶対心理を求めない」という立場をとる　=> 「道徳や法や制度にも絶対的な価値はない」という極端な考えにつながる => アテネでは、人々が独りよがりな主張をして、==詭弁==（屁理屈）が横行する
- ペロポネソス戦争
	- デロス同盟の盟主アテネ（民主政ポリスの中心で文化・芸術に秀でる）は、ペロポネソス同盟の盟主==スパルタ==（貴族政ポリスの中心で軍事に秀でる）とのペロポネソス戦争（前431から前404）において苦戦の連続で、最終的に敗れる。
	- アテネの全盛期は過ぎ、混乱・衰退期に突入していく
