教師の祖であるソフィストたちは、「世界や生き方はひとそれぞれ」、「考えても仕方がない」と[[03　ソフィスト（紀元前5世紀）#^2181a8 | 相対的心理]]を唱えた。これに対して、==ギリシア三大哲学者==は==絶対的心理==を探していく

# ソクラテス(前470～前390年)
- アテネの伝統的秩序が崩壊の危機に陥っていた衆愚政治の時期に、市民道徳の回復を目指し、自ら実践した哲学者
- 当時流行していたソフィストの相対的心理を否定し、普遍的な絶対心理を求め続けることが、人間本来のありかた、すなわち学問の出発点であると説いた　=> 倫理学の祖
- 悪は無知に由来すると考え、断片的な知識の集約ではなく、真の知を愛する姿勢(==愛知(フィロソフィア))==がただ他生きるだけでなく、==「善く生きる」==ことに通ずるとした
- ==徳（アテレー）==
	- すべての物事にはアテレー（徳）がある
	- アテレーとは、群を抜いて優れていること、卓越性のこと
		- 馬のアテレーは速く走ること
		- ナイフのアテレーはよく切れること
		- 人間のアテレーは==魂（プシュケー）への配慮==を怠らず「善く生きること」と説いた
- 堕落したアテネ市民の魂の世話をして、徳を取り戻したかった
- 人間が善い行いをできないのは、善悪・美醜（==善美の事柄==という絶対心理）について知らないからである => 知りさえすれば、必ず善い行いをする => 魂の徳を知ればそれを備える => 善く生きて徳を備えれば==幸福==になると説いた
- ## 生きざま
	- 父は石工、母は助産師
	- ペルシア戦争勝利後のアテネ全盛期に全半生を過ごし、当時は自然哲学を研究した
	- 30代後半
		- スパルタとのペロポネソス戦争がはじまり、3度の従軍を経験した勇猛な戦士だったが、この頃に関心の対象が自然から人間に移り、広場で青年たちを相手に問答を始める
	- 40歳ごろ
		- デルフォイのアポロン神殿で友人が==「ソクラテス以上の知者はいない」==という信託を受ける
		- 信託の内容を聞いたソクラテスは神殿を訪れ、そこに刻まれた==「汝自身を知れ」==という言葉を目にする => 絶対心理を知らないことを自覚していたこと（==無知の知==）を思想の出発点にし、自信を知者ではなく==愛知者==と呼ぶ
		- アテネに戻り、==問答法==（ディアレクティケー）で言葉を用いた対話をを通じ、人として互いに認められる最低限の共通基盤である理性を交わし、真理を気付かせた。
		- 無償で問答法をしていたので、ソフィストの顧客である政治家志望の青年が集まった
	- 60歳ごろ
		- プラトンに出会う
		- ペロポネソス戦争に敗れ、敗戦のゴタゴタでアテネ市民の一部から反感を買う => ソフィストや政治家から嫌われて==死刑を宣告==される
		- 友人から脱獄を進められたりもするが、==「悪法もまた法なり」==と述べ（法に反することは善く生きることに反する）、毒杯をあおって死ぬ

# プラトン（紀元前5世紀～前4世紀）
- ソクラテスが60歳ごろの時に20歳ごろのプラトンが出会う
- ソクラテスが死刑になったことで、アテネの政治に絶望して、哲学者になることを決意
- 師であるソクラテスを主人公にした対話篇を著する => ==ソクラテス自身の著書はない==
	- ==ソクラテスの弁明==
	- ==クリトン==
	- ==パイドン==
	- ==饗宴==
- 世界のあらゆる事物は「永遠不滅の本質」、「真の実在」である==イデア==を原型にしていると考えた
	- 世界は理性で捉える==イデア界==と資格・聴覚・嗅覚・触覚などの感覚で捉える==現象界==に分かれるという==二元論的世界観==を唱えた
	- プラトンはイデア界を太陽が照らす世界に、現象界を暗い洞窟にたとえた。人間は、洞窟の奥に閉じ込められた囚人のような存在で、壁に移る影絵を見て現実だと思い込んでいるだけと説明した
	- 人間の魂は生まれる前はイデア界にいたと考え、現象界でもイデアを想起できるとした
	- ==エロース==
		- 完全な魂がイデアに憧れ、それを思慕する恋や愛
- 理想主義の祖
	- 物体を万物の根源（アルケー）とする自然哲学に対して、精神の優位を説くイデア論を唱えた
	- 物よりも心を優位としたプラトンは、のちの近代哲学のドイツ観念論への伝統を確立した==理想主義の祖==といえる
- ==魂の三部分==
	- 人間の魂は==「理性」「気概」「欲望」==の三つからなるとした
	- ==四元徳==
		- 理性は==善のイデア==を認識する==知恵の徳==を持つ
		- 気概は理性に従う意思である==勇気の徳==を持つ
		- 欲望はそれを制御する==節制の徳==を持つ
		- 三つの徳が相互に==調和==すれば、魂の正しいあり方として==正義の徳==が実現するとした
	- ↑師のソクラテスの「魂に配慮して、善く生きること」を理論化した
- ==国家論==
	- 理想の国家を追求し、魂の三部分と四元徳を国家論に応用した
