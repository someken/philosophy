# 紀元前6世紀ごろ
- [[01 古代ギリシャ世界と神話（DC8世紀）| ポリス]]の市民たちは、征服地から調達した奴隷に仕事を任せることで、==閑暇（スコレー）==を手に入れた。
	- 自由時間があることから、公共の広場（アゴラ）での討論や体育場での鍛錬が盛んになる
	- 人間は神に運命を任せず、自らを成長させ生き抜くことに興味を覚えるようになる
- ギリシアやイオニア地方の市民たちは、地中海を隔てた各地と交易することで、ほかの地域にはまた別の神話があることを知る。自分たちの世界が唯一絶対のものではないと気付いた彼らは、「では、本当は世界は何からできるているのか？」と考え出す。これが万物の==根源（アルケー）==についての探求である。これが人類最古の学問とされる==（ギリシア）自然哲学==の出発点となる ^75ed21
# 自然哲学者たちとアルケー
- 何らかの物体を世界の根源と考えた思想家たちは、==自然哲学者==と呼ばれる
- ==タレス==（前624頃～前546頃）
	- すべての生命に必要不可欠なことから、アルケーを==水==とした
	- イオニア地方ミトレス出身で、「最初の哲学者」とされている
- ==アナクシマンドロス==
	- タレスと同じミトレス学派
	- アルケーを==無限なるもの（ト・アペイロン）==とし、万物は無限なるものから生まれそこへ帰る、無限の循環を繰り返すとした
- ==アナクシメネス==
	- アルケーを空気とし、生物が空気を吸って生きるように、万物は空気の希薄化や濃厚化から生まれるものとした
- ==ピタゴラス==
	- アルケーを数とした
	- 万物は数の比例係数によって調和し、秩序づけられていると考えた
- ==ヘラクレイトス==
	- イオニア地方エフェソス出身
	- すべてを破壊し変化させる力を持つことから、アルケーを==火==とした
	- 「万物は流転する（バンタ・レイ）」、「同じ河に二度と入ることはできない」と述べ、存在するものはすべて常に変化していると説く
- ==パルメニデス==
	- 南イタリアのエレア出身で、==エレア学派==の祖とされる
	- 「有る」という言葉を「決して有らぬことがない」と解釈する
	- 「有るものはあり、有らぬものはあらぬ」と述べ、アルケーを==在るもの==（生まれも消えもしない不動の存在）とした
	- 弟子の==エレアのゼノン==は、==アキレスと亀==で有名
- ==エンペドクレス==
	- シチリア島出身
	- アルケーを==四元素==（ 土・水・火・風)とする
- ==デモクリトス==
	- アブデラ出身
	- アルケーをそれ以上は分割できないもの、すなわち==原子==（アトム）とした。
	- あらゆる現象は原子の配列と運動によって説明できると、==原子論==を説く
	
- ギリシアやイオニアでは、人間を中心に一定の距離を取って物事を理性的に眺め、本質をとらえようとする==観想==（テオリア）という態度た生まれた
- 人々は[[01 古代ギリシャ世界と神話（DC8世紀）#^5f27ab | 神話]]（ミュトス）で説明する従来の世界観を否定し、人間の==理性==（ロゴス）に基づいて自然や社会を冷静にみつめ、合理的に世界を捉えようとした
- [[01 古代ギリシャ世界と神話（DC8世紀）#^169c16 | ポリス市民]]たちは、神話的世界観から合理的世界観へ転換した
